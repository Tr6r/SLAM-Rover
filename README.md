## Objectives of the Project
### Develop a robot capable of self-localization and 2D mapping.
## Features
- **2D Mapping:** Use a LiDAR to scan obstacle and generate 2D map.
- **Localization:** Use a 2-channel encoder to estimate odometry and improve real-time positioning accuracy.
- **Visualization:** Use RViz to visualize the generated map and the robot position.
